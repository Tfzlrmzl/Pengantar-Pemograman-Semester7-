*B. Jawaban Essay*
1. Jelaskan pengertian algoritma dan pemrograman serta berikan satu contoh penerapannya dalam kehidupan sehari-hari!
Algoritma adalah urutan langkah-langkah logis dan sistematis untuk menyelesaikan suatu masalah.
Pemrograman adalah proses membuat instruksi menggunakan bahasa pemrograman agar komputer dapat menjalankan tugas tertentu.
Contoh penerapan dalam kehidupan sehari-hari adalah membuat kopi:
1.	Siapkan gelas.
2.	Masukkan kopi dan gula.
3.	Tuangkan air panas.
4.	Aduk hingga merata.
5.	Kopi siap diminum.
2. Jelaskan perbedaan struktur Sequential, Selection, dan Looping dalam pemrograman. Berikan masing-masing satu contoh!
•	Sequential: Struktur program yang menjalankan instruksi secara berurutan dari awal hingga akhir.
Contoh: memasukkan nama, memasukkan umur, kemudian menampilkan nama dan umur.
•	Selection: Struktur program yang digunakan untuk menentukan pilihan berdasarkan kondisi tertentu.
Contoh: menggunakan if-else untuk menentukan bilangan ganjil atau genap.
•	Looping: Struktur program yang digunakan untuk menjalankan instruksi secara berulang selama kondisi tertentu terpenuhi.
Contoh: menggunakan for untuk menampilkan angka 1 sampai 10.
3. Jelaskan fungsi dari tipe data berikut dalam Java: int, double, String, char, dan boolean.
•	int: Menyimpan bilangan bulat, contohnya int umur = 20;.
•	double: Menyimpan bilangan desimal, contohnya double ipk = 3.75;.
•	String: Menyimpan teks atau kumpulan karakter, contohnya String nama = "Andi";.
•	char: Menyimpan satu karakter, contohnya char nilai = 'A';.
•	boolean: Menyimpan nilai benar atau salah (true atau false).
4. Jelaskan perbedaan penggunaan if-else dan switch-case dalam bahasa Java!
if-else digunakan untuk melakukan percabangan berdasarkan kondisi yang dapat berupa perbandingan maupun ekspresi logika.
Contoh:
int nilai = 80;

if (nilai >= 75) {
    System.out.println("Lulus");
} else {
    System.out.println("Tidak Lulus");
}
switch-case digunakan untuk memilih satu dari beberapa kemungkinan berdasarkan nilai suatu variabel atau ekspresi.
Contoh:
int pilihan = 2;

switch (pilihan) {
    case 1:
        System.out.println("Senin");
        break;
    case 2:
        System.out.println("Selasa");
        break;
    default:
        System.out.println("Pilihan tidak tersedia");
}
Perbedaannya adalah if-else lebih fleksibel untuk berbagai kondisi logika, sedangkan switch-case lebih praktis untuk pilihan berdasarkan nilai tertentu.
5. Jelaskan perbedaan perulangan for, while, dan do-while serta berikan contoh penggunaannya!
- For: Digunakan ketika jumlah pengulangan sudah diketahui.
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
- While: Digunakan ketika pengulangan bergantung pada kondisi tertentu dan kondisi diperiksa sebelum menjalankan instruksi.
int i = 1;

while (i <= 5) {
    System.out.println(i);
    i++;
}
- Do-while: Digunakan ketika instruksi harus dijalankan minimal satu kali sebelum kondisi diperiksa.
int i = 1;

do {
    System.out.println(i);
    i++;
} while (i <= 5);
